# 小游戏厅（Mini Game Hall）

纯前端 **10 款小游戏合集**，无任何框架与依赖——HTML / CSS / 原生 JavaScript 手写实现。

## 🕹️ 游戏列表

游戏介绍

贪吃蛇：闯关 + 无限双模式：60 关 = 6 张主题地图 × 10 关，逐关解锁；苹果 +5 / 西瓜 +6 / 草莓 +8 / 金苹果 +15；按剩余时间评 1~3 星；无限模式每 100 分切换地图  
俄罗斯方块：消行 100/300/500/800 分，连续消行连击 ×1.2/×1.5/×2，硬降每格 +2；累计消行升级（10 级）   
2048：方向键/WASD/滑动，里程碑制（2048/4096/8192 各庆祝一次），支持撤销 3 步   
打砖块：五段式 20 关，爆炸砖连锁 / 钢砖 / 移动砖 / 再生砖 / 5 种道具（加长·多球·慢速·激光·粘性）；通关条件：让小球打穿所有砖行   
扫雷：初/中/高三级 + 自定义棋盘（自定行列与雷数）；首击必安全、右键插旗、数字快查；按建议通关时间计分（最快 1 秒 +10）     
记忆翻牌：20 关：牌阵 4×3 → 6×5 递增   
Flappy 小鸟：扇翅穿管，缝隙随分数收窄   
五子棋：人机对战（启发式 AI：活三冲四、攻防加权）+ 悔棋 + 战绩存档   
数独：回溯法随机生成，三档难度挖洞，冲突高亮、键盘输入、提示功能   
跳一跳：按住蓄力松手起跳，落点虚线预览，落中心连击加成 

所有游戏进度（最高分 / 通关进度 / 星级）自动保存在浏览器 `localStorage`。

## 本地运行

方式一（部署到本地打开）：

```bash
python serve.py
# 浏览器打开 http://127.0.0.1:8803
```

方式二（点击链接）：

(https://beautybaby468.github.io/ai_game_platform/)

方式三：直接双击 `index.html` 也能玩（所有资源相对路径引用）。

## 📁 目录结构

```
├── index.html / style.css / script.js   # 游戏大厅（聚合各游戏最高纪录）
├── serve.py                             # 本地服务器（禁用缓存，改版即生效）
├── home-btn.css                         # 各游戏页共享的"返回大厅"悬浮按钮
├── snake/      tetris/      game2048/
├── breakout/   minesweeper/ memory/
└── flappy/     gomoku/      sudoku/    jump/
```

每个游戏都是独立文件夹，内部统一为三件套分离结构：`index.html`（页面）+ `style.css`（样式）+ `game.js`（逻辑），互不依赖，可单独抽出运行。

## 🛠️ 技术说明

- 零依赖、零构建，全部原生实现；Canvas（打砖块/Flappy/跳一跳）与 DOM（其余）混合架构
- 关卡/难度数值均以配置表驱动（如 `snake/LEVEL_TABLE`、`breakout/CFG`），方便调参扩展新关卡
